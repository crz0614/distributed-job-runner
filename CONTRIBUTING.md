# Contributing / 贡献指南

Thank you for your interest. Please open an issue before substantial changes.

感谢关注。进行较大修改前，请先创建 Issue 说明问题与方案。

## Workflow / 流程

1. Create a focused branch from `main`.
2. Keep commits small and descriptive.
3. Add or update tests for behavioral changes.
4. Run the repository's documented test, lint, and build commands.
5. Open a pull request describing scope, verification, and risks.

请从 `main` 创建独立分支；提交保持聚焦；行为变更必须补充测试；运行 README 中的测试、检查和构建命令；PR 必须说明范围、验证结果与风险。

Do not commit credentials, personal data, production records, generated secrets, or copied client material.

禁止提交凭据、个人信息、生产数据、生成的密钥或未经授权的客户资料。
