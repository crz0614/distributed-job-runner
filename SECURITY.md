# Security Policy / 安全政策

Please do not disclose vulnerabilities in public issues. Send a private report to the repository owner through GitHub with the affected component, reproduction steps, impact, and a minimal proof of concept. Do not include real credentials or personal data.

请勿在公开 Issue 中披露漏洞。请通过 GitHub 私下联系仓库所有者，并说明受影响组件、复现步骤、影响和最小化验证样例；不要提交真实凭据或个人数据。

Supported scope is the current `main` branch. Reports are acknowledged as soon as practical. No bug bounty or payment is implied unless agreed in writing before work begins.

当前支持范围为 `main` 分支。维护者会尽快确认报告；除非工作开始前另有书面约定，否则不承诺漏洞奖金或报酬。
